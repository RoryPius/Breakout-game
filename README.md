
Breakout Game
A classic arcade-style Breakout game built for the Kepoco handheld device.

What the Game Does
Control a paddle to bounce a ball and destroy all the bricks on screen. The game features:
	•	32 bricks arranged in a 4x8 grid
	•	3 lives - don't let the ball fall!
	•	Score tracking - 2 points per brick
	•	Progressive difficulty - ball and paddle speed up as you play
	•	Win condition - destroy all bricks to win


Tools Used
	•	Language: MicroPython
	•	Platform: Kepoco (72x40 pixel display)
	•	Libraries:
	•	kepoco.display - for graphics rendering
	•	kepoco.button - for input controls


How to Run It
On Kepoco Device:
	•	Upload files to your Kepoco:
	•	breakout_game.py
	•	demo.txt (optional - for automated demo)
	1	Open breakout_game.py in the Kepoco editor
	2	Run the game (press Play/Run button)
	•	Play using the controls:
	•	LEFT/RIGHT - Move paddle
	•	A - Restart game
	•	B - Exit game


Using Kepoco Web Editor:
	1	Go to https://www.cs.kent.ac.uk/kepoco/editor/
	2	Create a new file and paste the game code
	3	Save as breakout_game.py
	4	Click Run button to play in the emulator
Game Objective
Break all 32 bricks without losing 3 lives to win!
